# Git Push Checklist

- [ ] Install dependencies from `requirements.txt`
- [ ] Run `python -m py_compile main.py`
- [ ] Launch with `python main.py` and verify webcam opens
- [ ] Verify `t` toggles control ON/OFF
- [ ] Verify `q` / `Esc` exits and releases held keys
- [ ] Confirm browser focus behavior is documented in `README.md`
- [ ] Confirm one-hand mapping matches project scope
- [ ] Review all docs in `docs/` for clarity
- [ ] Run `git status` and ensure only intended files are included
